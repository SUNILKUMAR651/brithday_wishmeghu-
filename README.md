# 🎂 Indian Air Force 3D Birthday Celebration - Meghu (जिस्से) 🇮🇳✈️

An immersive 3D Indian Air Force themed birthday celebration web application dedicated to Meghu (जिस्से).

## ✨ Features

- ✈️ **Real-time Canvas 3D IAF Fighter Jet Flight Simulation**:
  - Su-30MKI / Tejas style delta-wing fighter jets flying across the sky with authentic camouflage, canards, afterburners, IAF roundels, and fin flash.
  - **Tricolor Smoke Trails (Tiranga)**: Saffron, White, and Green smoke ribbons billowing dynamically behind jets.
  - Formation flybys (Trishul formation, Vic formation, solo high-speed passes).
  - Interactive flight scrambled upon clicking anywhere on the sky.

- 🖼️ **Luxurious 3D Photo Frames**:
  - Golden bevels with metallic corner brackets, IAF Pilot Pride golden wings, glass reflection sheen, and 3D parallax tilt effects.
  - **Dual View Modes**:
    1. **3D Perspective Grid Mode**: Interactive cards with tilt physics and hover lift.
    2. **3D Cylindrical Ring Carousel Mode**: Rotating 3D space cylinder with auto-rotation and directional controls.
  - **Photo Management**: Upload your own photos dynamically, stored in browser LocalStorage.

- 🚀 **21-Jet Air Show Salute (सलामी)**:
  - Multi-jet aerobatic swarm crossing the screen with Tiranga smoke, celebratory fanfare, and confetti showers.

- 🔊 **Built-in Audio Synthesizer**:
  - Realistic Doppler Jet Flyby engine swoosh and celebratory birthday fanfare via Web Audio API.

## 🚀 How to Run Locally

Open `index.html` or `Megha.html` in any modern web browser.
